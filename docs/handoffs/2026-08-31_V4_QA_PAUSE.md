## What changed in V4 and must be reviewed/discussed during QA

### Durable mechanics / migration

D-0046 is implemented:

- ability modifiers are automatic from ability scores;
- Initiative = Dexterity modifier + explicit signed adjustment;
- saving throws = ability modifier + proficiency bonus when proficient + explicit signed adjustment;
- skills = associated ability modifier + proficiency contribution + explicit signed adjustment;
- skill training contribution is none / Competente / Pericia = 0× / 1× / 2× proficiency bonus;
- Passive Perception = 10 + final Perception skill + passive-specific signed adjustment;
- AC, HP, speed, proficiency bonus and spell save DC remain explicit/manual.

V3 → V4 migration is intended to preserve old displayed Initiative, saves, skills and Passive Perception totals. V3 did not store saving-throw proficiency, so migrated save proficiency must start unchecked and must **not** be guessed.

### Abilities / saving throws / skills

- all six ability scores remain in a compact row;
- automatic modifiers are now visible;
- saving throws have a distinct binary proficiency control;
- skills retain the liked compact control, now using one fixed footprint with empty / single-check / double-check states;
- `Pericia` must not consume a second box;
- explicit adjustment fields are the homebrew/gift escape path.

### Classes / hit dice

- `Artífice` is alphabetized with the class list;
- `Otro` remains last and opens a custom field;
- class/row padding was reduced;
- hit-die selector was widened so `d8`, `d10`, `d12`, etc. should remain on one line.

### Skill organization

- `Por habilidades` remains default;
- `Por atributo` remains alternate;
- the choice remains a user/device presentation preference;
- V4 replaces the previous dropdown with a direct segmented/two-state selector.

### Combat reference

Approved order implemented:

1. `CA` / `Iniciativa` / `Velocidad`;
2. `PG actuales` / `PG máximos` / `PG temporales`;
3. `Bonificador por competencia` / `Percepción pasiva` / `CD de salvación de conjuros`.

Labels may abbreviate when space requires it, but they must remain recognizable; avoid overly obscure abbreviations.

### Icons

Back, Settings/gear and similar icon-only actions are now stable vector/Canvas icon buttons rather than text glyphs affected by font scaling.

### Fonts / text size

Text-size options remain:

- 80%;
- 90%;
- 100% default;
- 115%;
- 130%.

V4 font QA set:

- Manrope — sans;
- Sora — sans;
- Barlow Condensed — condensed;
- IBM Plex Sans Condensed — condensed.

Atkinson was removed. No serif option is wanted.

Settings layout was changed to behave better above 100% text size. This still requires manual phone judgment, especially at 115% and 130%.

### Themes

Theme identities remain:

- Sistema;
- Claro;
- Oscuro;
- Gris claro;
- Morado oscuro.

V4 attempts to make `Gris claro` more visibly gray and `Morado oscuro` more clearly purple/distinct from ordinary Dark. Final palette acceptance remains open for owner QA.

### V3 regressions that must remain fixed

V4 must preserve the V3 passes:

- keyboard/IME does not trap or cover lower editable content;
- rotating portrait ↔ landscape does not return to start/campaign screen;
- screen off/on does not return to start/campaign screen;
- current PC/tab/unsaved draft survives normal recreation;
- landscape grouping remains stable with multiple classes;
- durable data and UI preferences persist correctly.
