# Rendered character-sheet visual references

This directory contains page-image renders of the owner's character-sheet PDF templates so repository readers and future agents can inspect the layouts even when direct PDF rendering is unavailable.

## Source mapping

- `original/page-1.png` through `original/page-5.png` are rendered from `../Hoja de PJ - 5.0 - Simkin.pdf`.
- `v2/page-1.png` through `v2/page-5.png` are rendered from `../Hoja de PJ v2 - 5.0 - Simkin.pdf`.

The renders are generated at 144 DPI and are convenience/inspection assets only. The PDFs remain the authoritative visual sources.

If a PDF is materially revised, regenerate the corresponding page images rather than manually editing the renders.
