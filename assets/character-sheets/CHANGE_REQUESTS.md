# Character Sheet Template Change Requests

This file records owner-side Adobe InDesign/PDF changes discovered during application design or implementation.

A coding agent must not assume it can silently redesign the owner's PDF templates. If a template needs a visual/layout/source change, add an entry here and explain it to the owner.

## Status values

- `Needed` — owner action required in Adobe InDesign.
- `In progress` — owner is editing the source template.
- `Ready for review` — revised export has been supplied.
- `Completed` — revised template has been accepted into the project.
- `Cancelled` — change is no longer required.
