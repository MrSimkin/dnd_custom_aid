# Para Hoja de PJ — owner-authored symbol font

Author/owner: **Gustavo Muñoz**.

On 2026-09-18 the owner explicitly authorized this project to include the original font in the public development repository and to modify/version it for DnD Custom Aid.

Rules:

- never overwrite an earlier version;
- one subfolder per version;
- every version has a human-readable mapping/use guide;
- preserve legacy mappings unless a deliberate compatibility-breaking decision is approved;
- font symbols remain rendering-layer conventions, never game/domain state.

The exact original binary is not available in the current chat/library, so the repository structure and generators are committed first. When it is available again, verify the known original SHA-256 before publishing/regenerating binaries.
